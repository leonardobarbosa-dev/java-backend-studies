# Java Backend Studies

Repositório criado para organizar meus estudos de Java 
com base no curso Maratona Java do DevDojo.

O projeto contém exemplos práticos, anotações e módulos organizados
com foco em aprendizado contínuo, prática e revisão futura.

---

## Objetivos

- Praticar fundamentos do Java e conceitos de backend
- Organizar os estudos por módulos e assuntos
- Manter um repositório estruturado para futuras revisões
- Documentar os conceitos aprendidos durante o curso

---
