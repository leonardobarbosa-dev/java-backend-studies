# Object-Oriented Programming (OOP)

Módulo focado nos principais conceitos de orientação a objetos.

Os exemplos deste pacote foram criados para praticar a modelagem de objetos,
organização de código e os recursos mais utilizados da programação orientada a objetos.

Além dos exemplos básicos, este módulo também contém pequenas variações e testes
utilizados durante os estudos e revisões dos conteúdos.

---

## Objetivo do Módulo

Este módulo foi desenvolvido para consolidar os principais conceitos
de orientação a objetos em Java, incluindo encapsulamento, reutilização,
abstração e polimorfismo.
