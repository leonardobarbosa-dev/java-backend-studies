# Fundamentals

Módulo inicial focado nos fundamentos da linguagem Java.

Os exemplos deste pacote foram criados para praticar a sintaxe básica da linguagem,
entender como os principais recursos funcionam e construir uma base sólida para os
próximos módulos do projeto.

---

## Conteúdos

### Classes iniciais

As primeiras classes foram utilizadas para introduzir os conceitos básicos
da linguagem e familiarizar o estudo com a estrutura de um programa Java.

1. Hello World
2. Primitive Types
3. Operators

---

### Pacotes de estudo

Os tópicos abaixo possuem pacotes próprios com exemplos organizados por assunto.

#### conditionals

Exemplos utilizando estruturas condicionais para controle de fluxo e tomada de decisão.

- if / else
- else if
- ternary operator
- switch

---

#### loops

Exemplos de estruturas de repetição e controle de iteração.

- while
- do-while
- for
- foreach
- break e continue

---

#### arrays

Exemplos relacionados à criação, manipulação e iteração de arrays em Java,
incluindo arrays multidimensionais.

- arrays unidimensionais
- inicialização de arrays
- percorrendo arrays
- matrizes
- arrays multidimensionais
- jagged arrays (arrays irregulares)
- iteração aninhada

---

## Objetivo do Módulo

Este módulo foi desenvolvido para consolidar os fundamentos da linguagem Java
antes do estudo de tópicos mais avançados, como orientação a objetos.
